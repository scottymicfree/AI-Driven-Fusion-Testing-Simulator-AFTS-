# Executive Summary

AFTS is a public architecture for building site-aware, AI-assisted fusion and acoustic-plasma simulators. It defines how independent implementations can represent local reference frames, connect replaceable physics engines, use AI without surrendering scientific authority, quantify uncertainty, preserve provenance, compare sites, and safely connect to laboratory hardware.

The architecture is intentionally not tied to Lucy, a particular interface, or a particular technology stack. Lucy Fusion Testing Studio is one future implementation. Others may build their own standalone applications from the same concept.
