# Contributing

Contributions may propose scientific corrections, clearer terminology, new validation cases, improved contracts, alternative implementation patterns, or independent implementation reports.

Contributors should:

1. Distinguish established physics from hypotheses and implementation choices.
2. Provide references or derivations for material scientific claims.
3. Preserve implementation neutrality.
4. State assumptions, units, coordinate conventions, and limitations.
5. Avoid claims of experimental success without reproducible evidence.
6. Keep hardware actuation guidance subordinate to independent safety systems and qualified human authority.

Changes to normative requirements should include a rationale, compatibility impact, validation method, and migration guidance.
