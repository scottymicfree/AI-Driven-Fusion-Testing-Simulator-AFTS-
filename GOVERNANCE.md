# Repository Governance

AFTS is maintained as an open architecture publication. Changes are evaluated against scientific integrity, implementation neutrality, reproducibility, safety, interoperability, and long-term clarity.

The repository uses semantic versioning. Patch releases clarify text without changing meaning. Minor releases add compatible concepts or optional profiles. Major releases may alter normative contracts and must include migration notes.

No single implementation, including Lucy Fusion Testing Studio, controls the meaning of the public specification. Implementation experience may inform the specification, but normative language remains platform-neutral.
