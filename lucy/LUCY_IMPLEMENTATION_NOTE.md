# Lucy Fusion Testing Studio - Non-Normative Implementation Note

Lucy may host AFTS as a native Fusion Testing Studio. In that implementation, Lucy can provide natural-language mission creation, governed agent coordination, Knowledge Fabric access, experiment scheduling, approvals, audit, cinematic visualization, and cross-Studio workflows.

Lucy and EMMA are not part of the AFTS public compliance boundary. An independent implementation may use entirely different orchestration, governance, interface, storage, and deployment systems.
